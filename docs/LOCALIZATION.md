# Локализация

В профиле, под оформлением, доступен выбор языка: «Как в Telegram», русский,
English, 简体中文 (упрощённый китайский), فارسی (персидский, фарси).

При первом открытии используется `Telegram.WebApp.initDataUnsafe.user.language_code`.
Варианты `en-*`, `zh-*`, `fa-*`, `ru-*` приводятся к поддерживаемому языку.
Для остальных языков и при открытии без Telegram используется русский.

Ручной выбор приоритетнее Telegram. Возврат к «Как в Telegram» снова включает
автовыбор. Настройка хранится в localStorage по ключу
`fikus:language:v1:tg:<user.id>`; для браузерного гостя используется отдельный ключ.
Настройка разделена по аккаунтам на данном устройстве. Синхронизации между
устройствами пока нет: проект не подключён к серверу. Telegram ID здесь служит
ключом предпочтений, а не подтверждением личности или авторизацией.

Переключение обновляет тексты, `html.lang`, `html.dir`, заголовок страницы,
числа и даты без перезагрузки. Для фарси включено RTL и системный шрифт
с поддержкой персидского. Валюты и числовые значения цен остаются исходными.
Поиск учитывает исходные и переведённые названия и описания.

Исходные тексты каталога и редактора сохраняются на русском: перевод применяется
при отображении. Введённые комментарии и отзывы не переводятся. Пользовательские
описания, отсутствующие в словарях, показываются без изменений.

Словари: `src/locales/{en,zh,fa}.json`, ключи — исходные русские строки.
Интерполяции `{{0}}`, `{{1}}` нужно сохранять в переводах. Первичные переводы
получены автоматически, основные термины интерфейса исправлены вручную;
для публикации профессионального перевода длинных условий нужна вычитка носителями.
В работающем приложении нет запросов к сервисам перевода.

Проверки: `npm test`, `npm run build`, `npm run test:localization`
(dev-сервер на 5174; другой адрес — через `QA_URL`). Браузерный тест подставляет
тестовые Telegram-профили; реальная авторизация Telegram им не проверяется.
Результаты: `docs/localization-checks.json`; скриншоты: `previews/localization/`.
