# Панель владельца фиКУС

Панель: `/#/admin/overview`. Вход по паролю `ADMIN_PASSWORD` из `.env`.
Локальное создание случайного пароля: `npm run setup:local`. `.env` и SQLite исключены из Git.

## Возможности

- **Обзор:** посетители, сессии, просмотры, нажатия, корзина, среднее активное время, график по дням и путь к оформлению.
- **Товары:** поиск, фильтры, быстрое скрытие, массовое включение/скрытие, дублирование, редактор всех полей и условий, JSON-импорт/экспорт.
- **Порядок ленты:** drag-and-drop на компьютере, стрелки на телефоне. Результат сохраняется сразу в `Catalog.productOrder`; фильтры не сбрасывают глобальный порядок. Внутри категории сохраняется тот же относительный порядок.
- **Категории:** добавление, название, тема, иллюстрация, порядок, скрытие вместе с товарами.
- **Отзывы:** общие между браузерами, очередь проверки, публикация/скрытие, ответ магазина. Текст и оценка покупателя не редактируются администратором. Изменение отзыва покупателем возвращает его на проверку, если включена премодерация.
- **Прямые ссылки:** случайный код на товар, подпись источника, копирование, счётчик переходов и отключение. Код не содержит ID товара и не возвращается публичным каталогом. Можно создать несколько источников на один товар.
- **Аналитика:** 24 часа / 7 / 30 / 90 дней, свой период, фильтр товара, динамика по дням, часы активности, подробная таблица товаров.
- **Действия клиентов:** сессии анонимных посетителей, история переходов и корзины; постраничная история и CSV показанной страницы (до 200 действий). У каждого открытия видны активные секунды именно этого просмотра.
- **Настройки:** продавец, часы, время ответа, общая информация и гарантия, тема первого входа, тексты витрины, объявление, Telegram-параметры, модерация и сбор аналитики. Общую сохранённую гарантию можно применить ко всем товарам.

## Вход и Telegram

Настраиваемые параметры панели:

- `botUsername` — username бота, например `my_shop_bot`.
- `appShortName` — пусто для Main Mini App, короткое имя для именованного Mini App.
- `adminTelegramIds` — ID владельцев через запятую; также можно задать `ADMIN_TELEGRAM_IDS` на сервере.

`BOT_TOKEN` и `ADMIN_PASSWORD` хранятся только в окружении сервера.
Telegram-вход проверяет HMAC исходной строки `initData`, `auth_date` (до часа) и ID владельца.
Парольный вход остаётся доступен после изменения Telegram ID. Сессия владельца действует 12 часов, cookie HttpOnly / SameSite=Lax, Secure в production.

Прямая ссылка: `https://t.me/<bot>[/<app>]?startapp=p_<random-code>`.
При открытии приложение обращается к серверу за товаром; отключённая ссылка, скрытый товар или скрытая категория не откроются.
Ссылка доступна любому получателю, которому её передали: это отключаемая ссылка, а не индивидуальная авторизация клиента.
Для работы внутри Telegram нужно предварительно настроить Main Mini App или именованное приложение в BotFather и HTTPS-адрес.

## Как считаются действия

Витрина обновляет каталог при смене экрана, возврате в приложение и раз в 30 секунд.

Данные поступают с витрины пакетами примерно раз в 5 секунд; активное время — дополнительно раз в 10 секунд. Повторные события с тем же ID не дублируются. На выходе используется `sendBeacon`. События сессии владельца игнорируются сервером.

- **Посетитель:** отдельный браузер с серверной cookie; это не проверенное число людей. Разные браузеры одного человека могут учитываться отдельно.
- **Сессия:** случайный код посещения; после 30 минут отсутствия действий создаётся новый.
- **Нажатие:** переход к карточке из интерфейса. Вход по прямой ссылке учитывается отдельно.
- **Просмотр:** фактическое открытие доступной карточки.
- **Активное время:** карточка видима, вкладка в фокусе, с последнего действия прошло не больше минуты. Фоновое время и длительный простой исключаются. Это браузерная оценка внимания, а не доказательство чтения.
- **Среднее время:** сумма активных секунд / число просмотров за выбранный период.
- **Добавление:** факт успешного добавления в корзину; количество единиц учитывается отдельно.
- **Конверсия в корзину:** доля сессий с просмотром, в которых было добавление в корзину. Это не доля оплаченных покупок.
- **Оформление и чат:** переходы, не подтверждение отправки сообщения или оплаты. Состав корзины связывает эти действия с фильтром товара.

Графики и свой диапазон дат используют `Europe/Moscow`. Обновление панели — каждые 30 секунд, также есть ручная кнопка. События старше 180 дней удаляются. Данные не уходят в сторонние системы аналитики. Клиентские метрики не используются для оплаты или выдачи.

## Хранение и проверки

Node.js 22.18+ со встроенным SQLite. Основные таблицы: state, admins, visitors, links, reviews, events, audit. Каталог и настройки используют ревизии: устаревшая вкладка получает конфликт вместо перезаписи чужих изменений.

```bash
npm test
npm run test:server
npm run build
npm run test:admin
```

Браузерные проверки запускают отдельный сервер с SQLite в памяти и изолированные контексты покупателя/владельца; рабочие данные и реальные Telegram-пользователи не затрагиваются. Скриншоты и результаты: `qa/admin/`. Для установленного Chromium можно передать `PLAYWRIGHT_CHROMIUM_EXECUTABLE`.

## Размещение на сервере

Этот этап требует адреса сервера и домена. В репозитории подготовлены Dockerfile и Compose. Они запускают отдельный сервис на `127.0.0.1:8787` и сохраняют базу в отдельном volume, не занимая публичные 80/443 и порты других ботов.

1. Установить пароль, токен и `PUBLIC_ORIGIN=https://<domain>` в `.env` на сервере.
2. Запустить `docker compose up -d --build`.
3. В существующем HTTPS nginx добавить proxy_pass на `http://127.0.0.1:8787`, передавая исходный Host. Не менять конфигурацию других ботов.
4. Проверить `/api/health`, вход в панель и ссылку из Telegram.

Пример фрагмента для существующего HTTPS server:

```nginx
location / {
    proxy_pass http://127.0.0.1:8787;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-Proto $scheme;
    client_max_body_size 2m;
}
```

Для резервной копии использовать SQLite online backup либо остановленный сервис с полным содержимым volume, включая WAL-файлы. Обновление образа не должно удалять volume.

Источники: [Telegram: проверка initData](https://core.telegram.org/bots/webapps#validating-data-received-via-the-mini-app), [Telegram: прямые ссылки](https://core.telegram.org/bots/webapps#direct-link-mini-apps), [Node.js SQLite](https://nodejs.org/api/sqlite.html).
