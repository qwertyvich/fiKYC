# Ссылки на разделы

В админке откройте **Прямые ссылки → Раздел**. Для каждого раздела каталога автоматически подготовлена постоянная ссылка. Выберите раздел в списке, скопируйте готовый адрес и добавьте его в пост Telegram-канала. Посетитель откроет мини-приложение сразу в этом разделе.

Для отдельного поста можно создать дополнительную ссылку: выберите раздел, заполните «Название / источник» и нажмите «Создать ссылку». У каждого адреса свой счётчик переходов и переключатель активности. После отключения ссылка перестаёт открывать раздел; сохранение настроек и перезапуск приложения её обратно не включают. Скрытый или удалённый раздел по ссылке не открывается. Пустой, но включённый раздел остаётся доступным.

Пример: объявление «Сегодня крупная поставка почтовых сервисов» → ссылка на **Почтовые сервисы**. В разделе собраны «Почта России», «Почта для бизнеса», «СДЭК ID», «СДЭК Бизнес».

Во вкладке **Товар** по-прежнему можно создавать адреса отдельных карточек. Старые адреса сохраняются. Ссылки на разделы используют префикс `g_` в `startapp`, на товары — `p_`; обе разновидности разрешаются сервером по случайному коду. Для нового раздела ссылка создаётся автоматически после сохранения каталога. Если бот пока не настроен, адреса будут созданы после настройки username.

При первом обновлении приложения раздел «Почта» переименовывается в «Почтовые сервисы», а товары СДЭК из стандартного раздела `identity` переносятся в `mail`. Пользовательское название категории и товары, уже перемещённые в другие категории, сохраняются. ID товаров, цены, отзывы и существующие ссылки остаются прежними. Эта миграция выполняется один раз; дальнейшие изменения продавца не отменяются.

## Настройка запуска в Telegram

Для адресов `https://t.me/имя_бота?startapp=...` владелец должен включить **Main Mini App** в BotFather и указать `https://kyc.kraken892.rest/`. Одной кнопки меню недостаточно. Если приложение зарегистрировано с отдельным коротким именем, задайте его в «Настройки → Telegram → Короткое имя Mini App»: ссылки будут иметь вид `https://t.me/имя_бота/короткое_имя?startapp=...`. Это настройка BotFather, через Bot API включить Main Mini App нельзя. См. https://core.telegram.org/bots/webapps#launching-the-main-mini-app .
