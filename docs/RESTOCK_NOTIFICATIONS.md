# Уведомления о пополнении

В админке откройте «Товары → Редактировать», увеличьте остаток и нажмите «Уведомить о пополнении». Поле «Сколько добавили» заполняется разницей остатков текущего редактирования; количество можно изменить вручную. Это количество новой поставки, а не общий остаток. Кнопка доступна для товаров с фиксированной ценой и наличием.

«Предпросмотр рассылки» сохраняет товар, формирует обложку и показывает число получателей. Ничего не отправляется до нажатия «Отправить … пользователям». Повторный запуск того же предпросмотра не создаёт новую рассылку. После изменения товара или количества нужен новый предпросмотр; через час он устаревает. Прогресс и последние пять рассылок видны в этом же блоке. Рассылку можно остановить; уже отправленные сообщения остаются у получателей.

Сообщение содержит название, количество поставки, цитату, соответствующий премиум-значок и зелёную кнопку, открывающую именно этот товар в Mini App отправившего бота. Картинка снимается с текущей обложки карточки в браузере продавца; загруженные изображения и их расположение учитываются. Стандартные карточки Claude используют MP4-анимации с теми же Clawd-сценами. Если у Claude своя загруженная обложка, отправляется она. Обложка, подпись, аудитория и ссылка фиксируются в предпросмотре и сохраняются в SQLite вместе с рассылкой.

Одна рассылка — одно сообщение на Telegram ID среди всех подключённых магазинов. Бот реквизитов не используется. Собираются только подтверждённые Telegram-посетители приложения и участники личных диалогов с ботами магазина. Исторические подтверждённые посетители также включаются; если основной бот не может написать пользователю, проверяется другой включённый магазин. Бот не может первым написать произвольному Telegram-пользователю. Неизвестных приложению старых подписчиков получить через Bot API задним числом нельзя.

Чёрный список, отписки, отключённые боты и недоступность товара проверяются повторно при отправке. Пользователь может нажать «Не уведомлять о пополнениях» или отправить `/stop`; для возобновления — `/notify`. Отписка действует во всех ботах магазина.

Очередь обрабатывает до одного получателя за 600 мс, с отдельной паузой между уведомлениями одному человеку. Ответ `429` соблюдает `retry_after`. Недоступный личный чат не останавливает остальных. Файловый ID Telegram кешируется отдельно для каждого бота. При запрете премиум-эмоджи сообщение повторяется с обычным значком. Неопределённый результат сетевой отправки и незавершённая отправка после перезапуска отмечаются «Без подтверждения» и автоматически не повторяются: Telegram не предоставляет ключ идемпотентности для sendPhoto/sendAnimation.

Анимации: `FFMPEG_PATH=/path/to/ffmpeg PLAYWRIGHT_CHROMIUM_EXECUTABLE=/path/to/chromium node scripts/render-restock-media.mjs`, затем `npm run build`. Production не требует браузера, FFmpeg или дополнительных Node-пакетов на сервере. Проверки: `node --test server/restocks.test.mjs` и `PLAYWRIGHT_CHROMIUM_EXECUTABLE=/path/to/chromium node scripts/qa-restocks.mjs`. Все проверки используют подставной Telegram API; реальная рассылка автоматически не запускается.
