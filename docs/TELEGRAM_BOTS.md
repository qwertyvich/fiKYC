# Telegram: оформление и воронки

Админка: `https://kyc.ggsellik.click/#/admin/bots`, вход подтверждённого продавца через Telegram.

Для каждого бота задаются тема (фиКУС / Claude), название, описание, краткое описание и первый раздел меню. Сначала сохраните настройки, затем нажмите «Применить оформление»: это установит анимированную аватарку, тексты, команды и кнопку «Каталог». Сообщения пользователям при применении оформления не отправляются.

В настройках уже подключённого бота можно загрузить свой аватар (PNG/JPG/WebP до 12 МБ). Браузер помещает его в квадрат 1024×1024 без обрезки и сохраняет JPG без исходных метаданных. Аватар хранится в SQLite и входит в резервные копии. Кнопка «Вернуть аватар темы» возвращает готовую анимацию. Изменения аватара публикуются только при применении оформления.

Новый токен вводится однократно, проверяется через getMe и хранится AES-256-GCM в SQLite. Ключ BOTS_ENCRYPTION_KEY — отдельный секрет окружения из 32 случайных байтов, hex. Обязательно сохраняйте его вместе с резервной копией конфигурации: без ключа восстановленные токены недоступны. Основной токен остаётся в BOT_TOKEN. Токены не возвращаются ни админскому, ни публичному API. GatewayReqBot подключить как магазин нельзя.

Бот не должен обслуживаться одновременно другим приложением: наличие webhook блокирует подключение, конфликт polling отображается в панели. Остановка меню сохраняет настройки. Отключённый дополнительный бот перестаёт быть источником подписей новых Telegram-сессий.

На /start и /menu бот отвечает анимацией с кнопками. Четыре раздела на странице, «Далее»/«Назад» меняют подпись и кнопки текущего сообщения. Выбранный приоритет выводится первым. Кнопки Mini App используют прямые ссылки p_/g_ и открывают собственную Telegram-сессию бота; каталог и баланс привязаны к одному Telegram ID на всех воронках. Скрытые товары и разделы исключаются. /help ведёт к менеджеру.

Обрабатываются только личные чаты с людьми. Есть отдельный запрет отправки сообщений в группы на уровне транспорта. Исходная группа реквизитов не используется этим модулем. Входящие задания и offset сохраняются в SQLite; старые команды до подключения пропускаются. Временные ошибки повторяются с задержкой, постоянные ошибки одного получателя не блокируют остальных. Нельзя гарантировать ровно одну доставку при обрыве соединения после принятия сообщения самим Telegram: sendAnimation не поддерживает idempotency key.

Под обложкой используются жирный заголовок и HTML-цитата `<blockquote>`, затем короткая подсказка выбора раздела и номер страницы. Цвет цитаты задаёт Telegram; произвольный фон или размер шрифта подписи через Bot API не настраиваются. `InlineKeyboardButton` не содержит параметра выравнивания текста: подписи кнопок отображаются по правилам клиента, без пробелов и невидимых символов для имитации выравнивания. Меню обновляется при следующем `/start` или `/menu`, уже доставленные сообщения массово не редактируются.

## Графика

Комплект: `/branding/telegram/fikus-telegram-branding.zip`. Исходные PNG, готовые JPG и MP4 аватары бота/оператора в обеих темах; GIF/MP4 описания 640×360; MP4 меню. Ролики H.264, yuv420p, 6 секунд, 15 кадров/с, без звука; GIF 12 кадров/с. Исходники генерации изображений и спецификации: `docs/TELEGRAM_BRANDING_PROMPTS.md`. Сборка анимации: `FFMPEG_PATH=/path/to/ffmpeg PLAYWRIGHT_CHROMIUM_EXECUTABLE=/path/to/chromium node scripts/render-telegram-branding.mjs`.

Картинку/анимацию блока описания Bot API устанавливать не умеет: загрузите `<theme>-description.gif` через **BotFather → /mybots → бот → Edit Bot → Edit Description Picture**. Аватарку личного аккаунта оператора установите в его профиле вручную; для неё есть JPG и MP4. Основное Mini App новых ботов включается в BotFather с URL текущего магазина `https://kyc.ggsellik.click/`; кнопки меню открывают Mini App и без этой настройки.

## Значки и цвета

Реальные custom_emoji_id взяты методом getStickerSet и проверены по изображениям наборов [DCMoji](https://t.me/addemoji/DCMoji) и [SberCX_emoji](https://t.me/addemoji/SberCX_emoji). Соответствия сохранены в `public/branding/telegram/emoji-manifest.json`: Claude — оранжевая звезда Anthropic, нейросети — AI-чип, почта — конверт. Общие действия — зелёные стрелки и сумка каталога. «Помощь менеджера» — зелёный контур профиля из [dinoemogichange](https://t.me/addemoji/dinoemogichange), индекс 3, `5314302441389334783`; соответствие проверено по кадру анимации, так как миниатюры набора содержат только начальную точку. Логотип Сбера не используется как обозначение магазина.

Telegram поддерживает style success (зелёный), primary (синий), danger (красный). Оранжевого style нет, поэтому кнопки Claude отличаются оранжевым премиум-значком и графикой. Premium emoji доступны ботам с дополнительным username, приобретённым на Fragment, либо если владелец бота имеет Telegram Premium. При отказе API меню повторно отправляется с обычными значками, предупреждение видно только администратору.

Источники: [Bot API](https://core.telegram.org/bots/api), [оформление ботов](https://core.telegram.org/bots/features), [Mini Apps](https://core.telegram.org/bots/webapps).
