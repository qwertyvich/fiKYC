# Страны и язык интерфейса

В обзор и аналитику добавлен отчёт по странам подключения: посетители, сессии и доля сессий за выбранный период. В списке сессий и CSV действий также указана страна. Одна сессия учитывается один раз; используется первая известная страна подключения в ней. Посетитель может учитываться в нескольких странах, если у него разные сессии через VPN.

Страна определяется локально по DB-IP Country Lite, отдельно для IPv4 и IPv6. Запросы к внешним геосервисам с IP посетителя не отправляются. В событиях хранится только двухбуквенный код страны. Источник: https://db-ip.com/ (CC BY 4.0). Упоминание DB-IP присутствует в интерфейсе отчёта.

Собственный Nginx перезаписывает заголовок `X-Fikus-Client-IP` адресом подключения. Приложение доверяет ему только при `TRUST_FIKUS_PROXY=true`; production Compose включает этот флаг, а порт приложения доступен только на 127.0.0.1. Клиентские поля страны, `CF-IPCountry` и произвольная цепочка `X-Forwarded-For` не используются.

База находится в `/opt/fikus-miniapp/shared/data/geoip/country.bin`, вне Git и релизов. `deploy/activate.sh` загружает первоначальную базу и устанавливает собственный таймер `fikus-geoip-update.timer`: обновление второго числа месяца около 03:40 по Москве. Скрипт `scripts/update-geoip.py` проверяет формат и целостность диапазонов и атомарно заменяет индекс. Приложение подхватывает новую базу в течение минуты. При временной ошибке обновления остаётся последняя исправная база.

Для посещений до включения функции страна неизвестна. VPN может менять результат; страна подключения не означает гражданство, язык или фактическое местонахождение.

Язык и оплата независимо от IP следуют языку Telegram; при его отсутствии — языку браузера. Поддерживаются RU/EN/ZH/FA; для остальных иностранных языков используется английский. Ранее сохранённые не привязанные к языку Telegram переопределения сбрасываются при переходе на новую версию. Новые ручные выборы действуют до смены языка Telegram, после чего вновь включается автоматический режим. То же правило применяется к выбору карты/USDT.

Тесты: `npm test`, `node --test server/*.test.mjs`, `node scripts/qa-startup.mjs`, `node scripts/qa-geo-language.mjs`. Они не отправляют реальные сообщения Telegram.

Отчёты читают события последовательно и считают часовые пояса по переходам смещения, а не через `Intl` для каждого события. На сервере расчёт выполняется в отдельном потоке с отдельным подключением SQLite только для чтения. Повторные одинаковые запросы объединяются; готовый отчёт кэшируется на 15 секунд. Число ожидающих расчётов и память потока ограничены, тайм-аут отчёта не останавливает API магазина. Разделы редактирования каталога и настроек не запускают фоновую загрузку аналитики. Регрессионная проверка содержит 180 000 событий времени и проверяет ответ API во время расчёта.
