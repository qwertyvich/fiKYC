# Проверка расширенного ассортимента

7 ноября 2026 года, Windows / Node.js 22.20.0. Проверки выполнены в отдельном Chromium, без пользовательского профиля.

- Production-сборка TypeScript/Vite: успешно.
- `npm test`: 10 проверок доменной логики, включая миграцию, новые позиции, валюты, доступность услуг, валидацию дат и числа гостей.
- `npm run test:ui`: 13 сценариев базового магазина, обновлённых под 51 предложение и 12 категорий.
- `npm run test:services`: 8 дополнительных сценариев. Проверены перенос сохранённого каталога без потери настроек, все категории, создание и сохранение заявки, ошибки дат, формы пополнения/карт, смешанная корзина RUB/USD, сохранение валют в истории, настройки услуг в редакторе, загрузка всех логотипов, ширины 320/390/440 px. Ошибок JavaScript не зафиксировано.
- Визуально проверен контактный лист всех 33 брендов. Файлы загружаются локально. Самодельный знак Claude заменён оригинальным SVG, источники и хеши записаны в `logo-sources.json`.

В окружении установлен Chromium 1248. При несовпадении версии Playwright можно явно указать существующий браузер:

```powershell
$env:PLAYWRIGHT_CHROMIUM_EXECUTABLE = 'C:\Users\tim\AppData\Local\ms-playwright\chromium-1248\chrome-win64\chrome.exe'
npm run test:ui
npm run test:services
```

Результат дополнительных проверок: `services-browser-checks.json`. Скриншоты находятся в `../qa/`: `official-logos.png`, `services-categories.png`, `services-request.png`, `services-mixed-cart.png`, `services-rental-320.png`, `services-rental-390.png`, `services-rental-440.png`.

Проверки относятся к локальному интерфейсу. Реальная оплата, выдача, отправка заявок оператору и Telegram WebView не проверялись и этим изменением не подключены. Параллельные изменения других сессий включены в текущие локальные проверки, но могут измениться после времени, указанного в JSON-отчёте.
