# Покупки и отзывы из Telegram-канала

Вход на серверную админку: откройте мини-приложение магазина в Telegram под привязанным аккаунтом продавца @tcmai, затем **Профиль → Панель администратора → Импорт из Telegram**. Адрес страницы — `https://kyc.kraken892.rest/#/admin/channel-import`, но обычный браузер без подтверждённой Telegram-сессии продавца доступ не получит. Парольный вход в production отключён.

1. Скачайте заполненный пример во вкладке импорта (или `examples/channel-import-example.json` в репозитории). Замените вымышленные данные примера реальными данными канала.
2. Скопируйте ID нужного товара из таблицы этой же вкладки. Например, `claude-kyc` — «Верификация KYC на ваш аккаунт». Название `name` служит вашей подписью и не переименовывает товар.
3. Загрузите файл, проверьте сводку и нажмите **Сохранить для ночного обновления**. Сразу покупателям ничего не публикуется. Новая версия заменяет предыдущую ожидающую версию.
4. В ближайшие **00:00 по Москве** сервер применит сохранённый файл целиком. Допуск запуска — до 30 секунд. При простое сервера пропущенное применение выполняется при старте.
5. При обновлении данных исправьте сохранённый файл и загрузите новую версию. Дополнительная команда запуска импорта не нужна. Сервер не имеет доступа к файлу на вашем компьютере и не наблюдает за Telegram-каналом сам.

## Формат

UTF-8 JSON, размер до 1 МБ. Корневые поля: `version: 1` и `products: []`.

| Поле товара | Значение |
| --- | --- |
| `id` | ID существующего товара в каталоге |
| `name` | Понятное вам название |
| `buyers` | Число покупателей из канала, целое число от 0 |
| `mark` | Средняя оценка в канале, число 1–5 с одним десятичным знаком; `null` — показывать среднее по опубликованным отзывам |
| `reviews` | Массив отзывов; можно оставить пустым |

| Поле отзыва | Значение |
| --- | --- |
| `id` | Постоянный ID, например `post-100-comment-45`. Сохраняйте его при правке текста или даты |
| `name` | Имя автора, до 60 символов |
| `mark` | Целая оценка 1–5 |
| `date` | `2026-11-08 14:30` по Москве или ISO со смещением, например `2026-11-08T14:30:00+03:00` |
| `text` | Текст отзыва, до 2000 символов; перенос строки записывается `\n` |

Для дробных чисел используйте точку: `4.7`. Не ставьте запятую после последнего поля JSON. ID отзыва уникален внутри товара; один автор может иметь несколько отзывов с разными ID.

## Даты и обновление

Невозможные даты (31 февраля, 24:00 и т. п.), неизвестные товары, повторяющиеся ID и неверные оценки отклоняют файл целиком с понятной ошибкой. Предыдущие данные сохраняются. Сохранённый файл проверяется повторно ежедневно. Если товар удалён из каталога до ночного применения, операция отклоняется целиком; ошибка появляется во вкладке импорта, предыдущая версия остаётся активной.

Будущие отзывы допускаются, но их текст, имя и оценка не возвращаются покупателям до указанного времени. После наступления времени они появляются при следующем обновлении страницы/фоновом обновлении приложения (до 30 секунд). Перезапуск сервера расписание не сбрасывает. В админке они отмечены «Запланирован».

Новая версия файла — полный снимок импорта: отсутствующие отзывы скрываются, отсутствующие показатели товаров убираются. Пустой `products: []` снимает весь импорт. Отзывы, оставленные в приложении, не затрагиваются. Повторное применение не создаёт дубли. Модерация и ответы магазина у существующих импортированных отзывов сохраняются, в том числе при исправлении текста и даты. Удалённый и затем возвращённый в файл отзыв считается повторно разрешённым администратором.

Импортированные отзывы помечены «Из Telegram». Сводная оценка `mark` и число покупателей подписаны как данные Telegram: сводная оценка может относиться к большему количеству комментариев, чем перенесено вручную. Среднее в блоке отзывов считается только по видимым опубликованным отзывам, включая новые отзывы приложения; будущие и скрытые отзывы в него не входят.

## Устройство

Копия загруженного JSON, активная версия, даты проверки и следующего применения хранятся в SQLite приложения (`channel_import_file`). Вместе с картой связей `channel_review_map` и показателями `channel_product_stats` они попадают в обычные резервные копии БД. Это постоянное серверное расписание, а не задача в чате с ассистентом. Telegram API для импорта не вызывается.

Маршруты `/api/admin/channel-import`, `/preview`, `/file` доступны только администратору. Просмотр файла не публикует данные. Файл, отложенные отзывы и ошибки доступны в админке. Публичная выдача дополнительно проверяет дату каждого отзыва.

## Заготовка для всего каталога

Кнопка **Скачать шаблон всех товаров** создаёт файл с текущими ID и названиями всех товаров, в порядке каталога (скрытые товары идут в конце). Для первых позиций предусмотрено примерно 50 слотов отзывов, к концу — около 7. Число колеблется между соседними товарами; заготовка не задаёт реальное количество отзывов или покупателей. Подготовленный файл текущего каталога также доступен в `examples/channel-import-all-products.json`.

- У товара заполните `buyers` реальным числом покупателей. `mark: null` оставьте для расчёта среднего по опубликованным отзывам либо замените средней оценкой своего канала.
- В нужном слоте отзыва заполните пустые `name`, `date` и `text`, замените примерную `mark` настоящей оценкой. ID уже проставлены; сохраняйте их при дальнейших правках.
- Слоты с одновременно пустыми `name`, `date` и `text` пропускаются. Товары с `buyers: null`, `mark: null` и без заполненных отзывов тоже пропускаются. Вручную удалять неиспользованные заготовки не нужно.
- Частично заполненный отзыв выдаёт ошибку с номером товара и отзыва. Файл, содержащий только пустые заготовки, нельзя поставить на применение.

Напоминание: файл остаётся полным снимком импорта. Не заменяйте уже заполненные отзывы пустыми заготовками в следующей версии, если хотите сохранить их опубликованными. Пустые заготовки не восстанавливают и не заменяют реальные отзывы.
