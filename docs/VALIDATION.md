# Проверка поставки

## Актуальная проверка: отзывы, корзина в Telegram и баланс

7 ноября 2026, Windows / Node.js 22.20.0. `npm run build` выполнен успешно; `npm test` — 19/19. Браузерные проверки в изолированных контекстах: 5/5 сценариев чата продавца и баланса, 6/6 отзывов и показателей, 8/8 ассортимента и услуг. Отдельно проверено 216 состояний форм: 30 услуг, обе темы и ширины 320/390/1280; ошибок отступов, переполнения и перекрытия кнопок нет.

Проверены: сохранение отзывов после перезагрузки, редактирование без дублирования, средняя оценка, изоляция предложений, синхронизация вкладок, отказ хранилища без потери текста, число покупателей в редакторе и каталоге; полный текст корзины с RUB/USD и комментарием, сохранение корзины, пустой контакт без исходящего перехода, состав URL при заданном тестовом контакте, сохранение параметров услуги; валидация пополнения и отсутствие зачисления при подготовке/копировании запроса.

Скриншоты `previews/reviews-*.png`, `seller-*.png`, `customer-balance-topup.png` визуально просмотрены. Отчёты: `reviews-checks.json`, `seller-checks.json`, `services-checks.json`, `form-spacing-checks.json`. Тестовые отзывы существуют только в изолированных контекстах проверки. Сообщения в Telegram не отправлялись. Приём оплаты, настоящий баланс и общие отзывы между устройствами не подключены. Актуальный сценарий описан в [SHOP-FLOW.md](SHOP-FLOW.md).

## Предыдущие проверки

Ниже сохранены результаты предыдущих этапов. Описанное создание локального заказа из корзины заменено подготовкой сообщения продавцу.

Локальная проверка 7 ноября 2026 года, Windows / Node.js 22.20.0.

- `npm run build`: TypeScript и production-сборка Vite успешно.
- `npm test`: 14/14 тестов домена и сценариев магазина — валюты, миграции, сохранение авторского каталога, валидация условий, глубокие ссылки, статусы и безопасные ссылки оплаты.
- Актуальный UI: 11/11 сценариев покупки и заявки (`commerce-checks.json`), 8/8 проверок расширенного каталога (`services-checks.json`), 6 групп проверок Clawd (`clawd-checks.json`). Ошибок JavaScript не зафиксировано. Production-сборка успешно собрана после правок.
- Chromium в отдельном изолированном контексте, без доступа к пользовательскому профилю браузера.
- Рендеры 320 / 390 / 440 / 1280 px: горизонтального переполнения страницы нет. Основные мобильные экраны визуально просмотрены; копии в `../previews/`.

Дополнительно проверены полный путь корзина → проверка → отдельный заказ, раздельные итоги RUB/USD, изменение остатков перед созданием заказа с сохранением комментария, восстановление прокрутки и поиска, inline-ошибки и черновик заявки после перезагрузки, копирование обращения с номером заказа без отправки, редактирование контактов и условий, все восемь состояний заказа, вход из объявления в конкретную карточку. Подробности — `UX-HANDOFF.md`; актуальные снимки — `../previews/ux-*.png`.

Ранее также проверенные сценарии базовой версии:

1. Начальный каталог, 12 позиций.
2. Обычный вход: Claude в его группе и карточке, возврат фиКУС в других группах.
3. Поиск и отсутствие результатов.
4. Фильтр наличия, сортировка, вид списком.
5. Избранное после перезагрузки.
6. Корзина, количество, сумма и сохранение демо-заказа.
7. Изменение описания/цены, порядок товаров/групп, скрытие группы и запрет прямой карточки скрытого товара.
8. Добавление группы и товара, экспорт JSON, отклонение неверного импорта, применение валидного импорта.
9. Вход Claude при скрытой группе: общий каталог с сохранением темы Claude.
10. Специальная ссылка: тема Claude в остальных разделах, профиле, корзине, заказах и помощи; поддержка `tgWebAppStartParam`.
11. Адаптивность 320 / 440 / 1280 px; основная проверка на 390 px.
12. Окно помещается в экран и не меняет высоту между длинным каталогом и пустыми заказами. Прокручивается только внутренний контейнер; нижняя навигация неподвижна, модальные окна ограничены рамкой приложения. Проверены окна 1280×420, 1280×720, 1280×1000 и 390×844.
13. Тема Telegram по умолчанию, тёмный фон до загрузки SDK, ручное переключение и сохранение после перезагрузки; правильное написание «фиКУС»; палитра `#d1fe17`; Claude в обоих режимах; выбор автоматического режима и реакция на изменение системной темы.

Для Claude сравниваются светлые значения `#faf9f5` / `#ffffff` / `#d97757` и тёмные `#141413` / `#1a1918` / `#c46849` с официальными токенами claude.com. Источники сохранены в `references/CLAUDE-PALETTE.md`.

Не проверялись: настоящий Telegram WebView, HTTPS-развёртывание, серверная авторизация, панель Руслана, платежи, выдача и работа реального бота. Они не подключены в этой версии. Скриншоты и локальные тесты не подтверждают коммерческую готовность магазина.
