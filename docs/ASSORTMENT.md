## Работа интерфейса

- Кнопка «Все категории» открывает полный список разделов. Поиск учитывает русские и английские названия, сокращения и синонимы.
- `saleMode: 'fixed'` (либо отсутствие поля) означает корзину; `saleMode: 'request'` — форму параметров и отдельную заявку.
- `requestKind` выбирает поля: пополнение, карта, верификация, финансовый сервис, профиль, аренда, бронирование, общая задача. `acceptingRequests: false` закрывает приём независимо от `stock`.
- Пополнения и карты запрашивают сервис, регион, сумму и валюту. Аренда — город и даты; бронирование — направление, даты и гостей. Для других услуг запрашивается задача.
- Цена `0` у заявки служебная и не отображается как бесплатная услуга; товары по запросу не попадают в корзину.
- `currency: 'RUB' | 'USD'` задаёт валюту товара; отсутствие означает RUB. Корзина и история показывают итоги отдельно для каждой валюты, без конвертации. Сортировка по цене группирует валюты и оставляет услуги по запросу в конце.
- В смешанном заказе `Order.total = null`: итог вычисляется из строк отдельно по валютам. Для одного вида валюты `total` содержит его сумму. Поле `currency` сохраняется в строках истории; прежние строки без него считаются рублёвыми.
- Редактор поддерживает формат продажи, валюту, тип полей заявки, приём заявок и синонимы поиска. Импорт проверяет эти поля.
- Однократная миграция `fikus:services-expanded-v2` добавляет отсутствующие позиции в сохранённый каталог, сохраняя пользовательские цены, порядок и скрытие групп. Последующие импорты не дополняются автоматически после завершённой миграции.

Методы адаптера заявок: `createRequest(productId, details)` и `loadRequests()`. Данные записываются в `fikus:requests`. Для реальной отправки оператору требуется серверный адаптер. Локальное сохранение не означает отправку или подтверждение услуги.

## Логотипы

Иллюстрации конкретных сервисов заменены реальными локальными файлами. Оригинальный знак Claude загружен с `https://claude.com/icon.svg`; математически нарисованный знак и самодельные логотипы сторонних брендов удалены. Общие услуги и категории используют иконки, а не вымышленные товарные знаки. Персонаж фиКУС относится к собственному оформлению магазина.

Файлы — `public/logos/`, карта использования — `src/logo-assets.json`. Для каждого из 33 брендов в `logo-sources.json` сохранены адрес страницы/поставщика, URL файла, время проверки и SHA-256 локального файла. Большинство файлов взяты с официальных сайтов, СДЭК/BelkaCar/Почта — из официальных Telegram-каналов, Outdoorsy — из App Store, издатель Outdoorsy, Inc. Загрузка логотипов при открытии магазина не обращается к сторонним сайтам.

Контактный лист: `../qa/official-logos.png`. Дополнительные сценарии проверки — `scripts/qa-services.mjs`; результат — `../qa/services-result.json`.

Магазин остаётся локальным frontend с демонстрационным хранилищем. Платежи, подтверждение заказов, реальная выдача и отправка оператору этим расширением не подключены.
