# фиКУС · Telegram Mini App

Обновление 7 ноября: **53 предложения в 12 категориях**, заявки на услуги, 11 тарифов в USD и реальные локальные логотипы 33 брендов. Новые цены перенесены из сообщения владельца; остальные услуги — по запросу. Раздел Jailbreak исключён. Подробности: [ассортимент](docs/ASSORTMENT.md), [проверка расширения](docs/ASSORTMENT-VALIDATION.md), [источники логотипов](docs/logo-sources.json).

Локально работающий интерфейс цифрового магазина на React + TypeScript + Vite. Подготовлен для интеграции с существующей панелью ботов.

Визуальная основа — Kalorii: Geologica, мягкие карточки и плавающая навигация. Актуальная палитра адаптирована из CSS официального Higgsfield: лайм `#d1fe17`, тёмный фон `#131517`, поверхности `#1c1e20`. Светлая версия разработана для фиКУСа как пара к тёмной. UX каталога взят из трёх предоставленных скриншотов mrkt: две колонки, разделы, поиск, сортировка, фильтры и быстрые действия. Исходный проект Kalorii не изменялся.

## Быстрый запуск

Нужен Node.js 22.18+ и npm. В Windows можно открыть **Start.cmd** — он установит зависимости при первом запуске и откроет браузер.

```powershell
npm ci
npm run dev
```

Обычный вход: http://127.0.0.1:5174/

Вход Claude: http://127.0.0.1:5174/?ref=klod

Редактор каталога: http://127.0.0.1:5174/#/admin — также доступен из профиля.

```powershell
npm run build   # TypeScript + production dist/
npm test        # проверки правил каталога и тем
npm run preview # просмотр dist/ на порту 4174
```

## Что работает

- Общий каталог: 53 предложения в 12 группах, цены в RUB/USD и услуги по запросу.
- Поиск по названию, подзаголовку и описанию; сортировка по цене, названию и ручному порядку; фильтр наличия; плитка / список.
- Структурированные объявления: результат, состав, требования, регион, период, выполнение и гарантия. Все условия редактируются в каталоге.
- Карточка с закреплённым действием, корзина и оформление через личный чат единственного продавца: готовый текст с позициями, количеством, итогами RUB/USD и комментарием. Услуги по запросу тоже готовят сообщение в чат. Старые демо-заказы и просмотр состояний сохранены.
- Черновики заявок и обращений, ошибки возле полей, восстановление поиска и прокрутки после возврата из карточки.
- Профиль покупателя с предпросмотром баланса RUB/USD, запросом пополнения продавцу и указанием оплаты с баланса в сообщении заказа. Реальный учёт, зачисления и списания требуют серверной интеграции.
- Контекстное обращение в поддержку, настраиваемые контакты и часы. Контакт продавца пока заглушка; до его настройки доступны предпросмотр и копирование сообщения.
- Светлый и тёмный режимы, независимо от оформления раздела (фиКУС / Claude). Переключатель солнце/луна в шапке; в профиле доступны «Светлая», «Тёмная», «Как в системе». Выбор сохраняется, при первом входе включён светлый режим. Автоматический режим следует Telegram или системным настройкам браузера.
- SVG-персонаж фиКУСа и локальные анимации Clawd с общим переключателем движения и статическими версиями для `prefers-reduced-motion`.
- Claude использует точные значения CSS официального claude.com: Clay `#d97757` / `#c46849`, фон `#faf9f5` / `#141413`, собственные нейтрали для карточек и текста. Источники и соответствие ролей: [docs/references/CLAUDE-PALETTE.md](docs/references/CLAUDE-PALETTE.md).
- Обычный вход: Claude-тема только в группе Claude и её карточках. На остальных экранах — фиКУС.
- Вход `ref=klod`, `ref=claude`, `tgWebAppStartParam=klod` или Telegram `start_param=klod`: старт в группе Claude, Claude-тема на всех экранах до конца сеанса. При скрытой группе открывается общий каталог.
- Локальный редактор: добавление и редактирование групп/товаров, описания, цены, остатки, значки, тема группы, ручной порядок, скрытие. Скрытие группы сохраняет товары и убирает их из каталога и корзины.
- Импорт и экспорт JSON; импорт валидируется. Изменения применяются после «Сохранить изменения».
- Telegram SDK: `ready`, `expand`, имя для отображения, BackButton, haptic feedback, безопасные отступы, цвет шапки.

## Границы этой версии

Это **frontend с локальным демо-адаптером**, не запущенный коммерческий магазин. Товары, цены, остатки и описания — примеры для замены владельцем. Услуги в примерах относятся к собственным профилям пользователя; реальные документы и учётные данные приложение не собирает.

Каталог, избранное, корзина и демо-заказы сохраняются в `localStorage` этого браузера, не синхронизируются между устройствами. Демо-заказ не списывает деньги, не выдаёт товар и не уменьшает остаток. Оплата, выдача, серверная авторизация, личный кабинет оператора и рабочая поддержка не подключены.

Редактор открыт для демонстрации и **не является защищённой админ-панелью**. Перед публикацией подключите серверную проверку прав или вынесите редактирование в существующую панель. `initDataUnsafe.user` используется только для подписи профиля, не для авторизации.

ФиКУС пока использует временный SVG-персонаж. В разделе Claude подключены локальные анимации Clawd и локальные шрифты; остальные логотипы также хранятся в проекте. Источники и лицензии сохранены в документации и рядом с активами.

## Проверка интерфейса

```powershell
npx playwright install chromium
npm run dev  # в отдельном терминале
npm run test:ui
```

QA работает в отдельном тестовом браузере, без данных пользовательского браузера. URL можно изменить через `QA_URL`, путь к уже установленному Chromium — через `PLAYWRIGHT_CHROMIUM_EXECUTABLE`. Результат и снимки сохраняются в игнорируемой папке `qa/`. Проверяются оба сценария темы, поиск, фильтры, избранное, демо-оформление, редактор и ширины 320 / 390 / 440 / 1280 px. Работа в настоящем Telegram WebView требует отдельной проверки после подключения бота и HTTPS.

## Отзывы и статистика предложений

В каталоге и карточке предложения показаны средняя оценка, число отзывов и покупателей. Отзывы можно добавить и изменить в карточке; оценка пересчитывается автоматически. В демоверсии отзывы сохраняются только в этом браузере (`fikus:reviews:v1`), покупки авторов не проверены. Один редактируемый отзыв на предложение в браузере.

Магазин одного продавца: отзывы относятся к предложениям магазина, отдельных профилей и рейтингов продавцов нет. Число покупателей задаётся в редакторе товара по данным магазина и сохраняется вместе с каталогом. Пустое значение отображается как «—», явный ноль — как «0». Демо-заказы не увеличивают число покупателей. Для общей статистики между устройствами нужен серверный источник отзывов и уникальных покупателей завершённых заказов.
